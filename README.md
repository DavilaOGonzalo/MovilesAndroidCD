# MovilesAndroidCD

Repositorio de trabajos, prácticas y proyectos desarrollados durante el aprendizaje de desarrollo de aplicaciones móviles.

## Tecnologías

- Kotlin
- Android Studio
- Jetpack Compose
- Git
- GitHub

## Contenido

Este repositorio contiene diferentes ejercicios, laboratorios y proyectos relacionados con el desarrollo de aplicaciones móviles para Android.

Los proyectos pueden incluir implementaciones realizadas de manera manual y otras desarrolladas con apoyo de herramientas de Inteligencia Artificial.

## Organización

Cada proyecto se encuentra organizado en sus respectivas carpetas para facilitar su desarrollo, seguimiento y revisión.

## Control de versiones

El desarrollo de los proyectos se gestiona utilizando Git y GitHub, registrando los avances mediante commits.
